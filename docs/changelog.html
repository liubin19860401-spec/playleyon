积分消耗口径说明

积分按智谱开放平台 API 用量折算：本项目使用 GLM-5.3-flash，输入 0.14 元/百万 token、输出 0.56 元/百万 token（缓存命中输入按 0.028 元/百万计）。单次迭代消耗 = 当次会话往返的输入+输出 token 折算金额；表中以「积分点」呈现（1 积分点 ≈ 0.01 元），便于横向对比。缓存命中率整体 96% 左右，因此成本显著低于无缓存基准。
