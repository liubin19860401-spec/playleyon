01

Gitee Pages 与 GitHub Pages 对比

维度Gitee PagesGitHub Pages
国内打开速度快（国内 CDN 节点）不稳定，部分网络无法打开
本机部署可行性网页直接传文件，无需凭据本机 443 直连失败，推送受阻
微信内打开正常视网络而定
实名要求需实名认证（一次，1–2 天审核）无需实名

已有 Gitee 账号且完成实名的 → 现在就能上线。没账号的 → 注册+实名要等审核，这期间可先用 GitHub 路径（见 GitHub Pages 指南的路径 B 网页上传，不受本机网络影响，因为上传走浏览器）。
02

部署步骤（约 5 分钟）

  1. 打开 gitee.com 登录（首次使用需注册并完成实名认证）
  2. 右上角 + → 新建仓库：仓库名 match3-demo，勾选「开源（公开）」，不要初始化 README，点「创建」
  3. 仓库页 → 文件 → 上传文件（或首页拖拽上传），把 D:\game_project\match3_demo\index.html 拖进去，填提交说明，点「提交」
  4. 仓库页 → 顶部 服务 → Gitee Pages（首次会让你选择部署分支）→ 分支 master、目录 /，点「启动」
  5. 等待约 1 分钟，页面给出访问地址，形如：
https://<你的Gitee用户名>.gitee.io/match3-demo/
把这个链接发到微信，朋友点开即玩。Gitee Pages 免费版在每次更新代码后需要到「服务 → Gitee Pages」手动点一次「更新」，此为唯一维护成本。
03

实名认证说明（首次使用才需要）

  1. Gitee 头像 → 设置 → 实名认证 → 按提示提交身份证信息（人工审核，一般 1–2 个工作日）
  2. 审核期间不影响注册、建仓、传文件，只影响开通 Pages 服务
04

更新代码的方法

  1. 修改本地 index.html（参数集中在文件顶部常量区）
  2. Gitee 仓库页 → 文件 → 找到 index.html → 编辑（网页在线编辑）→ 粘贴新内容 → 提交
  3. 服务 → Gitee Pages → 点「更新」→ 约 1 分钟生效
