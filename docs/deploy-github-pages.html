01

路径对比

路径 A：发我一个 Token推荐 · 全自动

你在 GitHub 网页上生成一个 fine-grained token 发我，我自动完成建仓、推送、开 Pages、验证线上可玩，最后把可分享链接直接发给你。全程约 5 分钟，你只需生成 token 这一步。

路径 B：网页手动上传零凭据 · 最快动手

你在 GitHub 网页上点 5 下：建仓 → 传文件 → 开 Pages。不需要任何 token，不碰命令行，10 分钟内出链接。

路径 C：本机浏览器登录一次登录长期有效

运行一条命令弹出 GitHub 登录窗口，授权后凭据存入 Windows 凭据管理器。以后每次更新代码只需 git push，适合持续迭代。

02

路径 A · 给我 Token 的步骤

  1. 浏览器打开 github.com 并登录 → 右上角头像 → Settings
  2. 左栏最底部 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. Token name 随意（如 match3-deploy）；Expiration 选 7 天即可，用完就废
  4. Repository access 选 All repositories 或仅指定新仓库均可；Permissions → Repository permissions 里勾选：Administration: Read and write（建仓+开Pages用）、Contents: Read and write（推代码用）
  5. Generate → 复制 github_pat_... 开头的 token 发到对话里
  6. 我接手完成后你会收到：仓库地址、线上链接、验证截图。token 用完建议立刻在网页上 Delete
03

路径 B · 网页手动上传（无需任何凭据给我）

  1. 登录 github.com → 右上角 + → New repository
  2. 仓库名填 match3-demo，选 Public（Pages 免费版要求公开），不要勾 README，点 Create repository
  3. 新仓库页点 uploading an existing file 链接，把 D:\game_project\match3_demo\index.html 拖进上传区，点 Commit changes
  4. 仓库页 → Settings → 左栏 Pages → Branch 选 main（若只有 master 则选 master）→ 目录 / (root) → Save
  5. 等 1–2 分钟，回到 Settings → Pages 顶部出现绿框地址，即你的游戏链接：
https://<你的用户名>.github.io/match3-demo/
注意 URL 末尾的 / 别丢；把这条链接发到微信对话框，朋友点开即玩。
04

路径 C · 本机浏览器授权登录

在任意终端执行（项目目录内）：

git credential-manager github login

会弹出 GitHub 登录窗口 → 浏览器授权 → 凭据自动存入 Windows 凭据管理器。完成后回来说一声「已登录」，我立即续跑建仓推送全流程。此凭据长期有效，以后改完代码 git push 一次即更新线上。

05

微信里分享与打开

  1. 复制 Pages 链接，直接粘贴发给朋友（单人或群）——微信会自动生成带标题「消消乐 · 色块 Demo」的卡片
  2. 朋友点卡片 → 微信内置浏览器直接开玩，无需下载、无需登录
  3. 想要更方便传播：把链接做成二维码（微信搜「二维码生成」小程序），长按识别即开
微信内置浏览器偶有缓存：更新代码后若朋友看到的还是旧版，让对方点右上角「…」→「刷新」即可。
06

上线后更新代码的方法

  1. 改 index.html（参数区集中了棋盘尺寸/颜色数/动画时长/计分基数）
  2. 项目目录下执行：git add index.html → git commit -m "update" → git push
  3. 约 1 分钟后 Pages 自动更新（Actions 页可看构建进度）
