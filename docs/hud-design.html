现状：得分与连击平级并排、目标分缩在角落；棋盘直接浮在插画上，边界靠 92% 白底硬撑。
问题具体表现影响
① 信息层级平得分、目标、连击、时间、步数五个数字同等大小挤在一行，得分没有视觉特权玩家扫一眼抓不到「我现在多少分」，辨识度低
② 与背景抢戏HUD 直接叠在插画上，只有一条黑分割线，无面板感背景越花，数字越看不清
③ 棋盘无框6×6 色块区没有任何边框装饰，像一张浮着的贴纸缺少「游戏机」质感，操作区域边界感弱

另一个隐藏问题：目标分没有「进度感」——玩家看不到还差多少，这是积分板辨识度问题的本质（不只是字小）。

积分板规范（可直接照抄）

元素规格
面板深墨渐变 rgba(28,27,26,.94)，圆角 10px，1.5px 墨描边，下方 14px 投影，左右留边 10px
得分26px / 800 等宽粗体 / 纯白，独占左侧 C 位
目标15px 琥珀色 #ffb224 右对齐；下方 6px 高进度条（琥珀→红渐变），实时填充得分占比
连击胶囊徽章：待机灰描边「×0」，激活变红底白字（现有 .on 逻辑复用）
第二行倒计时 / 剩余步数 / 关卡号三等分，虚线分隔；倒计时 ≤5s 变红（沿用现有逻辑）
棋盘框3px 墨描边 + 内缩 8px 白细线（双线画框），圆角 8px，投影加强到 20px
为什么深色面板：背景插画是多彩的，只有深色底能让白字得分在「任何一张背景」上都稳定可读——浅色面板在遇到亮色插画时还会复发辨识度问题。
03

棋盘边框两方案对比

边框 A · 双线画框推荐
A：墨色粗描边 + 内衬白细线（outline 内缩实现）。现代桌游感，与深色 HUD 面板同一语言，实现成本最低（纯 border+outline）。
边框 B · 木框钉饰备选
B：深木色 4px 边框 + 四角铆钉圆点 + 内衬白线。实体玩具感更强、更「游戏机」，但木色需要与五张背景插画的色调都兼容，风险略高。
维度A 双线画框B 木框钉饰
与背景兼容性墨色中性，五张背景全兼容木色偏暖，遇冷色调插画可能打架
与 HUD 面板配套同一墨色语言，成套感强面板是深墨、棋盘是木色，两套语言
实现成本border + outline，零图片border + 4 个伪元素铆钉
质感方向现代桌游 / 干净实体玩具 / 复古

推荐组合：深色仪表牌 HUD + 边框 A。整体是一套「深墨 + 纸色 + 单红 accent」的现代桌游语言，辨识度和质感同时解决，且与现有色彩体系零冲突。
